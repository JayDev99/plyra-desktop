# Plyra Chess desktop (Tauri)

A fast native window for Plyra Chess: Train (reviews, practice, rated puzzles, Woodpecker, opening drills) and
the Plyra School, bundled with the app, with signed automatic updates. See PLAN.md.

Release: raise `version` in `src-tauri/tauri.conf.json`, then run the **release** workflow (Actions tab).
Installed copies update themselves at their next start.
